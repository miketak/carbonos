# Tasks

Each task page gets one job done. The first line names the role you need,
the steps say where to click before what to type, and the end of the page
says what you will see when it worked and what changed elsewhere.

The tasks are grouped by where they happen in the product:

| Area | In the product |
| --- | --- |
| Account | Requesting access, setting your password, editing your profile |
| Organization | **Settings**, **Legal entities**, **Facilities**, **Units** |
| Activity data | **Activity data**, its records and source documents |
| Emission factors | **Emission factors** |
| Inventories and runs | **Inventories** and the workbench tabs **Records**, **Boundary**, **Method**, **Runs** |
| Reporting | The workbench tab **Report** and a run's report page |
| Base year | **Base year** |
| Factor updates | **Updates** |
| Administration | The administration console: **Dashboard**, **Access requests**, **Users**, **Organizations**, **Factor packs**, **Platform settings** |

The task pages arrive area by area over the coming releases of the help.
