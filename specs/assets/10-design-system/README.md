# Spec 10 assets

The approved workbench mockup, as the owner signed it off on 2026-10-03.

- `tokens.css`: the design system as one style sheet: the light and dark
  token sets on `.cos` and `.cos[data-theme='dark']`, and the component
  classes every screen uses. The token table in spec 10 is derived from it.
- `mockup/`: one artboard per screen (`*.dc.html`) and the canvas index. The
  artboards are the Design canvas format of the clickable mockup at
  <https://claude.ai/artifact/KDKR7QHSZe6incbVwkMjeW>; they read as plain
  HTML with `{{holes}}` and need that runtime to play, so open the canvas
  for the interactive version and read these for the markup and the copy.
