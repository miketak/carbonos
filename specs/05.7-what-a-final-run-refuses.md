# 05.7: What a final run refuses

- **Status**: Implemented (2026-09-17)
- **Protocol**: Chapter 1 (accuracy: reduce uncertainty as far as
  practicable), Chapter 4 and the 2013 required-gases amendment (one GWP
  set across the inventory), Chapter 9 (disclosure of assumptions), ISO
  14064-1:2018 section 6.2 (quantification approach) and 8.3 (uncertainty)
- **Owner**: Michael Takrama
- **Created**: 2026-09-17 (GHG inventory officer review of the 2026-09-16
  walkthrough)
- **Modules**: `ghg` (`InventoryService.designateFinal`, `finalHolds`, the
  EMISSION_FACTOR gate), `src/features/ghg` (the run page)

## Problem

A run may carry a planning value: a typical density stands in until the
supplier's certificate arrives, and the gate warns. Nothing stopped that run
from being designated the final result, which the report, the publication
and the base year attach to. Likewise a blend whose CO2e the source
publishes under AR5 was applied as published in an AR6 inventory, two sets
in one figure, with only a note.

## Behavior

- **A final run is refused** (409, naming the records) while any included
  classified record:
  - converts through a **typical density** without the classification being
    flagged as a **proxy with a justification**: "'Diesel by tanker' converts
    through the typical density of Diesel (0.84 kg/litre), a planning value:
    record the supplier's density under Units, or flag the classification
    as a proxy with a justification that says why the typical value stands
    (spec 02.2)." A supplier density carries its own source; a typical value
    stays only as a documented proxy, which the report prints on the line.
  - uses a **blend whose CO2e is published under another GWP set and cannot
    be re-derived** (no composition recorded): "... whose CO2e is published
    under AR5 and cannot be re-derived under AR6 (no composition recorded):
    record the blend's composition, choose a factor on AR6, or run the
    inventory on AR5 (one GWP set across the inventory)."
- **The gate says so first.** The EMISSION_FACTOR gate warns on both while
  the inventory is a draft, in the same words, so nothing surprises the
  reviewer at the final designation. A warning never blocks a run: the draft
  run is where the planning value is allowed.
- **The report prints the basis.** A factor row whose published basis
  differs from the inventory's set reads "CO2e as published, AR5; not
  rebased" in the GWP column (spec 07.4), on the page and in the PDF.
- Publication needs a final run (spec 05.1), so the same holds reach it.

## API

`POST /runs/{id}/finalize` returns 409 with the holds in `detail`.

## Non-goals and open questions

- A typical density with a citation is not a third route: the seeded typical
  values are planning values without one (spec 02.2 non-goals), and the proxy
  flag is where the justification lives.
- The hold is at the final designation, not at freeze, so a draft run can
  still be compared and reviewed with the planning value in place.
