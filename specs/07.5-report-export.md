# 07.5: Report export

- **Status**: Implemented
- **Protocol**: Chapter 9 (the report is the deliverable), Chapter 10 and
  ISO 14064-3 (a verifier re-performs a sample from the calculation file)
- **Owner**: Michael Takrama
- **Created**: 2026-09-09 (audit finding F38, ticket T-06); implemented
  2026-09-09
- **Modules**: `ghg` (the export endpoints, `ReportPdf`, `RunCsv`),
  `src/features/ghg` (download buttons on the run page)

## Problem

The run page had no export. The report could not leave the browser except
by copy and paste. Board packs, lender covenants and Ghana EPA submissions
need a document; a verifier needs a calculation file to re-perform a sample
and the frozen boundary and factor set the numbers rest on.

## Behavior

- **PDF report.** `GET /runs/{id}/report.pdf` renders the report in the
  order of Chapter 9 (spec 07.1, 07.4): the header block, the company and
  boundary version, the operational boundary declaration, the period,
  emissions by scope with both scope 2 methods, the market-based method and
  its instruments, the breakdown tables, each gas with the reconciling row
  of spec 07.7, biogenic CO2, the base year, the methodology and factor table, the
  exclusions, and the snapshot lines. A voided run's PDF carries a VOIDED
  banner on every page. The document is built from the run's snapshot, so
  the same run downloads the same document every time; the file name is
  `<organization>-<period label>-run-<number>.pdf`.
- **CSV of the lines.** `GET /runs/{id}/lines.csv` has one row per snapshot
  line with: line id, the parent line id and kind for a derived line (spec
  04.7), record id, facility, legal entity, country, activity
  type, evidence reference, period start and end, quantity and unit, factor
  id, factor name, factor unit, converted quantity, conversion factor, kg
  CO2e per unit, GWP set, accounting share, period share, kg CO2e, kg of
  each gas, biogenic CO2, the unsplit CO2e of spec 07.7, the reporting
  basis of spec 02.4, and the market-based columns. Excluded records
  follow in `GET /runs/{id}/exclusions.csv`, with the estimate state and
  the gas of spec 04.8. Numbers are plain decimals
  with a dot; the file is UTF-8 with a header row.
- **Frozen inputs.** `GET /runs/{id}/inputs.json` serializes the boundary
  version the run cites (entries, windows, shares, exclusions), the factor
  set the run applied (spec 07.4), the contractual instruments, the residual
  mix and the upstream rules (spec 04.7) as recorded, and the run's period, approach and GWP set.
- **Identical on repeat.** Every export derives from the run's snapshot
  tables only, never from live facts. The CSV and JSON files are
  byte-identical on repeated download; the PDF's content is identical (the
  PDF container carries its own creation stamp and document id, as the
  format requires).
- The run page offers the three downloads; the PDF opens in a new tab.

## API

- `GET /runs/{id}/report.pdf` → `application/pdf`,
  `Content-Disposition: attachment`.
- `GET /runs/{id}/lines.csv`, `GET /runs/{id}/exclusions.csv` → `text/csv`.
- `GET /runs/{id}/inputs.json` → `application/json`.
- All four are tenant-checked like the report (404 for an outsider).

## Data

None. Every export reads the run's snapshot tables.

None.

## Non-goals and open questions

- XLSX; the CSV opens in every spreadsheet.
- An evidence pack with attached documents (ticket T-15).
- A print stylesheet; the PDF is the print form. Its labels, dates and
  page layout are spec 07.8.
