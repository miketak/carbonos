## Failed cases (product defects)

- P3 I1.1 FAIL (Major): the register's Search box loses keystrokes. The input is controlled straight from the URL (`useActivityFilters` in activityFilters.ts, `set({ q })` on every keystroke → setSearchParams → refetch); typing "diesel" at 250 ms/char left "ds", at 700 ms/char "deel". Fix: local input state, URL synced (debounced). Same pattern in inventoryFilters.ts may affect the workbench search. A pasted/URL query works (?q=diesel&facility=… lists ACT-0004 alone).
- P4 C1.1/C1.3 FAIL (Minor bug, clear fix): the pre-flight panel does not refresh after **Save declaration**. `useSetOperationalBoundary` (useGhg.ts) only does setQueryData(inventoryKey) and never invalidates validationKey, so the "declared as covered but no included record..." warning appears only after a reload, and stays after the reason is saved until the next reload. The API (/validation) is correct both ways. One-line fix: invalidate validationKey(inventoryId) in onSuccess.
- P7 B1.2 FAIL (Major, two frontend bugs in PublishEditionDialog.tsx): (a) the "approver must not be the curator" condition is hard-coded `<GateItem met>` so the curator sees it as ✓ Met and an enabled Publish button; (b) the backend refuses with GhgFieldException(field "approver") → 422 with fields, and the dialog's onError puts field errors into `errors`, which has no "approver" field to render, so the curator sees nothing at all: no toast, no alert, dialog unchanged. Backend message is right: "The approver must not be the curator. Admin built this draft, so somebody else checks it against the source document and publishes it." (doc quote is the older wording "...so somebody else publishes it."; the seeded admin's display name is "Admin", not "Admin A").
- P8 B1.4 FAIL (Major, UI): while the base-year gate is BLOCKED the workbench's pre-flight `ready` is false and **Launch calculation run** is unavailable ("Launch on hold"), although the refusal text itself promises "Calculation runs stay available, because quantifying the movement is how a recalculation is assessed." The API accepts the run: POST /inventories/{FY2026}/runs → 201 (Run 002 created via curl). The UI should gate the launch on the run-blocking gates only, not on BASE_YEAR.
